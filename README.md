随着人机交互方式的不断演进，传统鼠标与键盘在特定场景下存在局限，例如在远程演示、虚拟现实、无障碍交互等环境中，用户需要更自然、更直观的操作方式。  本项目基于MediaPipe手部姿态识别技术，通过摄像头实时捕捉手部动作，将手势映射为鼠标的基本功能，实现了非接触式、直观灵活的交互体验

### 想到的可能应用场景：
- 外科医生在查阅医学影像（如CT、MRI）时，无需触碰鼠标或键盘，通过手势即可进行放大、翻页、标注等操作，避免了交叉感染的风险
- 实验员或工程师在操作过程中，可以隔空控制演示文稿或数据界面。

### 局限性：    
- 遮挡问题：MediaPipe在手部被部分遮挡时，关键点追踪会丢失或出错，导致功能失效。
- 用户适应性：目前的手势映射是我们预设的，缺乏用户自定义功能。不同用户可能习惯不同的手势。 
- 疲劳度：长时间抬起手臂进行“空中鼠标”操作，容易导致用户疲劳，这限制了长时间连续使用的可能性。
- 防误触和低延迟其实是一个”互相矛盾”的问题，这个问题很难找到理论上的最优解，所以我们目前只能是经过各种的实验找一个感觉上的最优解，未来可能会考虑自己训练模型尝试解决这个问题

### 未来的发展： 
因为技术问题还有待很久的研究，所以我们项目目前考虑的是可以把应用场景具体化定制化，比如针对医疗场景，可以进行调研看医生在具体场景中最常用的手势是什么，最常用的功能是什么，然后针对这样的手势和功能进行一个对应，可能只需要几个简单的手势和几个简单的功能，在特定的场景下，去针对这样的场景做专门的手势检测精确度也会更高，功能简单的情况下性能也会更好
